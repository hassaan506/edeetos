Platform Updates

A complete record of all features, performance upgrades, and security protocols deployed to EDEETOS.

July 14, 2026

v1.1.0 - Reward System Overhaul & Security Patch

Major Update
  • Security Prevented Reward Cheating: Fixed an exploit where resetting course progress or clearing data could allow a user to claim the same milestone reward multiple times.
  • Feature Instant Study Book Unlocks: Claiming a milestone book reward now opens the digital book in your account immediately. No more waiting for admin deployment or manual coordination.
  • Feature Smart Reward Options: The milestone pop-up now automatically checks what you own. It hides books or courses you already have lifetime access to so you never accidentally pick a redundant reward.
  • Feature Instant Password Reset: Added a standard "Forgot Password" link to the login screen so you can securely reset your credentials via email without messaging support.
  • Feature Saved Claim Alerts: If you close the milestone window without picking a reward, the platform saves your choice and displays it on your dashboard next time so you never lose an earned prize.
  • UI/UX Streamlined Choices: Rebuilt the milestone unlock window into a single, clean menu that lets you clearly toggle between a course extension and an instant book claim before submitting.
  • Bug Fix Accurate Milestone Tracking: Fixed the milestone counter logic. Trophies now correctly calculate your running total of flawless answers (10, 110, 610) instead of throwing off the math.
  • Bug Fix Fixed False Session Warnings: Fixed an issue where exiting a quiz cleanly using the exit buttons still caused a false "session ended unexpectedly" warning on your next visit.

  • UI/UX Accessibility Overhaul: Upgraded top navigation, timer, and lab value UI components to a high-contrast dark slate theme for optimal readability. Added rapid 'Next Question' routing inside the explanation modal.
