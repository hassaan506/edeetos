EDEETOS Changelog

Stay up to date with the latest features, performance upgrades, and bug fixes added to your study platform.

Just Now

v2.0.0 - The Performance & Cart Update

Major Update
  • Performance Lazy-Loading Engine: Books and heavy question banks now load on-demand, reducing initial dashboard load times by up to 80%.
  • Feature Unified Study Cart: Practice and Exam modes now share a powerful multi-select cart system allowing you to mix and match multiple topics across subjects.
  • Feature Premium Book Locks: Books in the library are now individually locked and display real-time access status based on your subscription.
  • UI/UX Spaced Repetition Overhaul: The "Due for Revision" panel has been completely redesigned to match the modern glassmorphism aesthetic.
  • Bug Fix Fixed an issue where switching between Practice and Exam modes inside a book would accidentally clear the topic selection grid.
Recently

v1.9.0 - Admin & Access Controls

  • Feature Course Change Requests: Students can now officially request an Admin to change their assigned exam course via the Profile menu.
  • System Book Bundle Pricing: The Premium checkout now automatically applies 10%, 20%, and 30% discount mathematics when purchasing multiple reference books.
  • Security Group Study Loophole Closed: Free tier users are now strictly prevented from using 4-digit room codes to bypass paywalls and join Premium study sessions.
  • Feature Advanced Key Generation: Admins can now generate redeem codes that grant access to specific individual books alongside standard courses.
Earlier

v1.8.0 - Strict Course Targeting

  • Feature Locked Dashboards: The Question Bank launcher is now strictly locked to the student's assigned database course, preventing accidental access to irrelevant exams.
  • UI/UX Streamlined Registration: Removed redundant 'Target Exam' and 'Year of Study' dropdowns in favor of a single master "Access Course" selector to speed up onboarding.
  • Bug Fix Removed hardcoded fallback defaults that were forcing unassigned legacy users into the FCPS Part 1 database.
